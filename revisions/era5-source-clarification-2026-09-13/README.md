# ERA5 source clarification

Chapter 3 and its presentation now state explicitly that the atmospheric data
are ERA5 pressure-level fields produced by ECMWF/Copernicus. The analysis
accesses those fields through Earthmover's public cloud-optimised ERA5 copy on
AWS. Earthmover distributes the losslessly stored copy; it is not a separate
meteorological reanalysis and “Earthmover” is not part of the meaning of ERA5.

No meteorological input, numerical result, figure or interpretation changed.
`manuscript-review.json` records the completed 138-page thesis build and chains
this editorial clarification to the preceding reviewed manuscript.
