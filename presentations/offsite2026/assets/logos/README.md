unchanged from his Downloads folder. No logo was redrawn or recoloured; Beamer
preserves the original aspect ratios.

`logo-ILB-BLK.pdf`, `logo_square.png`) are not used. The first has a tagline,
the second has a smaller institute name, and the last has large transparent
margins around its wordmark. Rebuilds use only the local files above.
